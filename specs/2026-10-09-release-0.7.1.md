# 0.7.1 发布说明

本版在 0.7.0 基础上同步已通过用户实测的公共登录修复，源码与 Windows 安装包使用同一提交构建。

## 更新内容

- 支持 Amazon 登录过程中出现的已保存账号选择页；仅在准确域名、路径及页面结构匹配时，选择第一个可见的已有账号。
- 所有店铺复用公共登录模块，不按店铺名称或 ID 特判；未出现该页面的流程沿用原有路径，不额外打开页面。
- 修复帮助页脚样式类被误判为额外账号验证的问题；真正的验证码、错误及混合登录控件继续进入原处理分支。
- 初次登录重定向尚未完成绘制时，复用有截止时间的只读等待，避免过早显示人工继续；不增加刷新、猜测地址或新建标签页。
- 补充延迟绘制、错误域名、页面结构变化、选择顺序及重试边界测试。

## 保持不变

- 不修改提现、GPSR、Feedback 的业务提交规则、资金防重复约束、队列和排期逻辑。
- 不新增数据库迁移；从 0.7.0 升级保留现有配置、建档和运行历史。
- 安装包不携带开发机数据库、凭据、日志、截图或测试账号数据。
- 保留 0.7.0 发布与安装包，不覆盖旧附件。

## 验证说明

- 用户已反馈本地真实登录测试通过；本次发布不额外执行真实店铺任务。
- 发布构建从安装包暂存源码运行完整测试；DOM 回归仅使用断网临时渲染器和脱敏样本，不访问 Amazon。
- 最终测试结果、构建提交和安装包 SHA256 随 GitHub Release 及发布清单提供。
